Every defect below was found by using the product or by reconciling it against
an independent implementation, not by reading code for style. Each carries a
reproduction, a severity, a root cause, the fix, the regression test that now
holds it, and the journey that was re-run afterwards.

Severity: **P0** a demo-stopper; **P1** a wrong or misleading answer a reader
would act on; **P2** a broken or confusing control; **P3** a cosmetic or
wording defect.
