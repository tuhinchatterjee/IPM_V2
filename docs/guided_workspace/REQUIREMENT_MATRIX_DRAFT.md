## Method

1. Every ID was extracted from the specification with the section heading it sits under.
2. Each ID was searched literally (with `-`/no-`-` and lower-case test-name variants) in `tests/cockpit_v4/test_gw_*.py`, `tests/cockpit_v4/test_whatif_*.py`, `frontend/src/**/*.test.ts`, `tests/guided_workspace/browser/gw.browser.mjs`, `docs/guided_workspace/evidence/journeys.json` and `docs/guided_workspace/*.md`.
3. Where the ID is not cited, the requirement text was matched to the test, unit test or browser journey that asserts the behaviour. Each cited test body or journey was opened and read. A test is cited only if its assertions cover the requirement.
4. Seeded artefacts (CORP/RET templates, LENS-xx, Mxxx) are traced to the seed definition plus the tests that count, validate and render the seeded set. Lens content was compared by hand with the visuals and metrics in `backend/workspace/lens_seed.py`.
5. Browser journeys are the `GW-Pn-nn` ids in `gw.browser.mjs`. All 41 recorded PASS in `journeys.json`, run as MODEL MOCK (scripted analyst, no provider credential).
6. Tests marked "Runs on `.venv-whatif`" need the ML runtime. They skip on the accepted interpreter (PHASE_LEDGER P6).

Status values: **COVERED** — at least one automated test or journey asserts it. **PARTIAL** — part is asserted; the gap is stated. **PENDING-P14** — needs the Mac live-provider UAT or a real credential. **PENDING-P13/P15** — belongs to the regression or handoff phase not yet run. **NOT COVERED** — no evidence found.
